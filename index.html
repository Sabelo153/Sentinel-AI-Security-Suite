About the project

Security operations, built step by step.

A development project by Sabelo Andile Biyela in Durban, South Africa.

Sentinel combines a PHP application and API, a MySQL/MariaDB data layer, web interfaces and a Kotlin Android guard client. Work includes occurrence records, incidents, attendance, patrols and device management.

The project is in development. Architecture documents include future plans alongside implemented components.

What you can use here

Browse the project and switch between sample product views. Login, account creation and live operational records require a separately hosted Sentinel server; they are not available on this GitHub Pages site. All displayed operations data is fictional.

# Sentinel Engineering Handbook

## 01. Project Vision

### Version
- Product version: 0.1.0
- Codename: Foundation
- Current milestone: Milestone 1 - Foundation

### Mission
Build a commercial-grade security operations platform that combines operational control, auditable workflows, and intelligent automation.

### Product Principles
- Every milestone must produce working software.
- Security is part of delivery, not a later phase.
- Modules must be reusable across web, API, mobile, and AI surfaces.
- Business rules belong in application and domain code, not controllers.
- Public APIs must remain stable and predictable.

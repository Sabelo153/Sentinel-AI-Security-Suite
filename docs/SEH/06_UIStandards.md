# Sentinel Engineering Handbook

## 06. UI Standards

### Objectives
- Operational clarity over decoration.
- Fast scanning for security supervisors and managers.
- Consistent patterns between web dashboard and Android app.

### Dashboard Priorities
Version 1 dashboard should reserve space for:
- Today's Attendance
- Open Incidents
- Visitors On Site
- Patrol Completion
- Vehicle Inspections
- Fire Equipment Status
- Recent Activity
- AI Insights

### UI Rules
- Use consistent spacing and typography.
- Keep forms short and grouped by business task.
- Validation errors must be shown next to the affected field when possible.
- Avoid ambiguous labels and actions.
- Use status colors consistently across modules.

### Accessibility
- Keyboard navigation must work for web UI.
- Color must not be the only status signal.
- Text contrast must remain readable in operational environments.

### Naming
UI labels should match domain vocabulary used in API and documentation.

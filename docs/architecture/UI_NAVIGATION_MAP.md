# Sentinel UI Navigation Map

Status: Draft v1.0 (constitution artifact 7 of 7)
Last updated: 2026-08-06

## Purpose
Define every major screen and navigation boundary across Sentinel applications so UX scales consistently with platform permissions and capabilities.

## Applications
- Sentinel Admin
- Sentinel Operations
- Sentinel HR
- Sentinel Finance
- Sentinel Payroll
- Sentinel Procurement
- Sentinel Fleet
- Sentinel Assets
- Sentinel AI
- Sentinel Cyber
- Sentinel CRM
- Sentinel Client Portal
- Sentinel Mobile
- Sentinel Reporting

## Navigation Standard
Each application map should define:
- Primary menu groups
- Screen inventory
- Entry points and required permissions
- Cross-application handoff points
- Mobile/offline availability flags

## High-Level Navigation Baseline
1. Dashboard and alerts
2. Master data management
3. Transactional workflows
4. Approvals and exceptions
5. Reporting and exports
6. Administration and settings

## Permission Coupling Rule
- Menu visibility must be driven by capability and permission grants.
- Screen actions must align to action + field + scope model.

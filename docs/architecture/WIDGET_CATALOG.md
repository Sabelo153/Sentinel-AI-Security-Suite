# Sentinel Widget Catalog

Status: Draft v1.0
Last updated: 2026-08-06

## Purpose
Catalog reusable dashboard widgets that can be composed into different persona dashboards.

## Widget Types
- KPI widget
- Alert widget
- List widget
- Timeline widget
- Map widget
- Chart widget
- Summary widget
- Action queue widget
- Recently viewed widget
- AI insight widget

## Widget Metadata
Each widget should define:
- widget_id
- widget_name
- widget_type
- data_source
- permissions_required
- refresh_interval
- placement rules
- size options

## Approval Checklist
- Widget inventory approved
- Widget-to-persona mapping reviewed
- Permission and data-source constraints documented

# Sentinel Dashboard Catalog

Status: Draft v1.0
Last updated: 2026-08-06

## Purpose
Define the dashboard inventory for each application profile so the platform has a consistent and intentional experience model.

## Dashboard Principles
- Every dashboard must reflect the user’s application profile.
- Dashboards should prioritize KPIs, exceptions, actions, and priority alerts.
- Each dashboard must support role-aware and scope-aware visibility.
- Dashboards should be dynamic and composable rather than hard-coded by module.

## Dashboard Inventory

### Guard Dashboard
- Shift status
- Patrol progress
- Assigned incidents
- Visitor queue
- Messages and alerts
- Training reminders
- Emergency actions

### Site Dashboard
- Site readiness
- Patrol compliance
- Incident summary
- Visitor and vehicle activity
- Equipment status
- Key and access issues
- Site AI insights

### Operations Dashboard
- Multi-site health overview
- Active incidents
- Patrol coverage
- Shift status
- Response team availability
- Risk indicators
- Control room activity

### HR Dashboard
- Workforce overview
- Compliance status
- Leave and attendance exceptions
- Training expiry
- Employee lifecycle status
- HR AI recommendations

### Finance Dashboard
- Revenue and receivables overview
- Payables and payroll queue
- Cashflow and budget indicators
- Exceptions and approvals
- Cost centre health

### Executive Dashboard
- Revenue, profit, and growth indicators
- Contract health
- Operational risk summary
- Client performance
- Compliance and cyber indicators
- Strategic KPI summary

### Board Dashboard
- Board pack status
- Financial statements
- Risk register
- Audit findings
- Cyber score
- Strategic initiative summary

### Client Dashboard
- Site service status
- Incident summary
- Visitor and attendance activity
- Invoice and service issues
- Requests and communications

### Technician Dashboard
- Installation workload
- Maintenance backlog
- Inventory issues
- Work-order queue
- Device health and alerts

### SOC Dashboard
- National or regional map view
- Live incidents and alerts
- Active guards and vehicles
- AI alert feed
- Cyber and weather overlays

### Admin Dashboard
- System health
- Integration health
- User and permission exceptions
- Audit activity
- Feature flag status
- Licensing alerts

## Dashboard Composition Standard
Each dashboard should include:
- Summary KPI widgets
- Action queue widgets
- Alert widgets
- Recent activity widgets
- Navigation shortcuts
- AI insight widgets where relevant

## Approval Checklist
- Dashboard inventory approved
- Dashboard-to-profile mapping reviewed
- KPI and widget standards documented
- Mobile and desktop dashboard variants considered

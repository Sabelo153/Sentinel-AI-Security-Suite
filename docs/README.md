## Enterprise Constitution (Mandatory Baseline)
Major feature expansion requires approval of these seven artifacts:
1. Entity Catalog
2. Relationship Model (ERD)
3. Permission Matrix
4. Workflow Catalog
5. Event Catalog
6. API Contract Catalog
7. UI Navigation Map

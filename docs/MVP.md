# Sentinel MVP Definition

## Version
- Product version: 1.0 MVP definition
- Current engineering baseline: 0.1.0 Foundation

## Core Question
What is the smallest version of Sentinel that a security company would pay for monthly because it replaces paper processes and gives managers live operational visibility?

## MVP Answer
The MVP is a digital security operations platform for guard companies that replaces paper occurrence books, manual attendance registers, handwritten incident reports, and patrol notebooks.

## Target Customer
- Small to mid-sized private security companies
- 20 to 300 guards
- 1 to 20 active sites
- Owner-managed or supervisor-led operations
- Teams currently using paper books, WhatsApp, and spreadsheets

## Problem Sentinel Solves
Sentinel reduces operational chaos by centralizing:
- guard attendance
- occurrence logging
- incident reporting
- patrol reporting
- management oversight
- exportable records for clients and compliance

## Included in MVP
- Login
- Dashboard
- Company and site structure
- Employee management
- User management
- Guard clock in and clock out
- Occurrence book entries
- Incident reports
- Patrol reports
- PDF export
- AI report enhancement
- Roles and permissions
- Audit logging

## Explicitly Excluded from MVP
- AI chat assistant
- Messenger
- Sentinel OS
- Billing and subscriptions
- Advanced analytics
- Fire drill module
- Vehicle tracking
- Visitor management
- Mobile offline sync
- White-label branding
- Multi-tenant cloud marketplace

## MVP User Roles
- Company owner/admin
- Operations manager
- Site supervisor
- Guard

## MVP Success Criteria
A customer should be able to:
- create employees and user accounts
- assign guards to sites
- clock guards in and out digitally
- record occurrence book entries on-site
- file incident reports with structured details
- submit patrol reports
- export professional PDF records
- improve report wording with AI assistance
- view operational summaries from a dashboard

## Version 1.0 Boundary
Version 1.0 is complete when the system can replace paper books for daily security operations at a real company.

## Product Principle
No feature enters the MVP unless it directly improves daily security operations or shortens the path to first paying customers.

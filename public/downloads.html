Install on a phone

  1. Confirm this is your company's trusted HTTPS address.
  2. Download the APK. If Android requests permission, allow installation from this specific browser or file manager according to company policy.
  3. Install and open Sentinel Guard. Connect it to the company server using the setup code or administrator configuration.
  4. Keep the same application signing identity for future updates. Updates with a different signing key cannot replace the installed app.

Phone manufacturers, Android versions and company policies may impose their own installation requirements. Do not disable device security or erase app data to get around a failed update.

Managed or offline phones

IT can transfer the signed APK using USB or an approved local file channel. For ADB-based test/IT installation, use adb install -r sentinel-guard.apk. Install the APK and approved camera/radio apps before enabling kiosk restrictions. Release installation restrictions before a supervised update, then restore the reviewed policy.

Offline QR decoding is bundled in the APK. Camera capture uses the phone's installed camera app; kiosk devices must allow that camera package. No scanner app or model download from Play Store is needed.

Update without Play Store

Return to this page or use your company's private distribution channel. Install a newer, correctly signed version over the existing app to preserve its data. Never uninstall or clear storage while encrypted reports remain queued.

The SHA-256 checksum checks file integrity. Verify the publisher/signing certificate through your company administrator before the first installation. This page does not silently install applications or bypass Android's installation controls.
